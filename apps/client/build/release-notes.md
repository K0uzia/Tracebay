## Tracebay 3.6.2

### PDF
- Le nom et le logo imprimés en en-tête des PDF (lots, disques, commandes, dons, prêts) sont désormais un réglage de l'atelier, défini par l'administrateur du serveur et commun à tous les postes. Ils ne sont plus écrits en dur dans l'application.
- Sans réglage, les PDF portent le nom « Tracebay », sans logo.

### Paramètres
- À propos : nouveau bloc « Atelier », qui affiche le nom et le logo en vigueur.

### À savoir
- Mettre à jour le serveur et enregistrer le nom et le logo de l'atelier avant de publier cette version sur les postes (procédure dans la documentation de déploiement du serveur). Sinon, les PDF portent le nom « Tracebay », sans logo, jusqu'à ce que le réglage soit fait.
- Aucune migration de données.
